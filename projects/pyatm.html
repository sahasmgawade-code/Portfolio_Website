Project 03

PyATM — ATM Simulation System

Oct – Nov 2025

A bank management web app simulating core ATM logic end to end, with an admin portal to create, update, and manage customer accounts.

  • Card activation/deactivation, account creation, and deletion workflows for admins.
  • Automated email and SMS alerts for account activity, sent via SMTP and an SMS gateway.
  • Bank statement generation and export in PDF and Excel formats.
Tech Stack
Frontend
HTML5 CSS3 Vanilla JavaScript Jinja2 templates
Backend
Python Flask Microsoft SQL Server (pyodbc)
Integrations
xhtml2pdf (PDF generation) SMTP Email Alerts SMS Gateway API
